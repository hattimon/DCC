# DCC Remote Access 0.1.0

## English

- Adds an opt-in, digest-pinned zrok 2 sidecar managed from the DCC App Store and administrative settings.
- Reserves a reusable public HTTPS address. DCC verifies the endpoint before accepting public panel traffic.
- Adds local-only management, administrator MFA, encrypted enrollment, a public ingress lease and an emergency digest blocklist.

## Polski

- Dodaje opcjonalny kontener zrok 2 z przypiętym digestem oraz zarządzanie w sklepie i ustawieniach DCC Web.
- Rezerwuje stały adres HTTPS. Panel dopuszcza ruch po sprawdzeniu rzeczywistej dostępności adresu.
- Dodaje lokalne zarządzanie, MFA administratora, szyfrowanie środowiska, kontrolę dostępności panelu i awaryjną blokadę digestu.
