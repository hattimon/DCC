# DCC Web 0.3.7

## Polski

- Wykrywanie danych dostępowych obsługuje zagnieżdżony JSON, wartości w cudzysłowach i dodatkowe formaty klucz–wartość. Rozpoznane sekrety są maskowane w zwykłym podglądzie i eksporcie logów.
- Logi przewijają się do najnowszego wpisu. Dodano limity 30 i 50 linii oraz odświeżanie co 1, 3, 5, 10, 15, 30 lub 60 sekund.
- „Aktualizuj bezpiecznie obraz” używa nowszego obrazu wybranego przez DCC Updatera i jego procedury wycofania. Ustawienia oraz dane pozostają w dotychczasowym wolumenie.

## English

- Access detail detection supports nested JSON, quoted values and additional key–value formats. Recognized secrets are masked in regular log views and exports.
- Logs scroll to the latest entry. The view adds 30- and 50-line limits and live refresh every 1, 3, 5, 10, 15, 30 or 60 seconds.
- Safely update image applies the newer image selected by DCC Updater and uses its rollback procedure. Settings and data stay in the existing volume.
