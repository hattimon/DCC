# DCC Web 0.3.1

EN: Container panel labels and copied links keep the configured Docker host address. Public entry opens recognized web panels through a session-protected DCC gateway, including verified SSH forwarding, isolated service cookies, forms, assets, ES modules and bounded SSE/WebSocket connections. Local HTTP/HTTPS links stay direct. The global option preserves a saved manual choice. See [setup, trust model and compatibility limits](docs/panels.md).

PL: Etykiety paneli i kopiowane linki zachowują skonfigurowany adres hosta Docker. Przy publicznym wejściu rozpoznane panele otwierają się przez sesję DCC, ze zweryfikowanym przekazywaniem SSH, osobnymi cookies, formularzami, zasobami, modułami JS i ograniczonymi połączeniami SSE/WebSocket. Lokalne HTTP/HTTPS zachowują linki bezpośrednie. Globalna opcja pamięta ręczny wybór. [Konfiguracja i ograniczenia](docs/panels.pl.md).

Source download after publication: [DCC-Web-0.3.1-source.zip](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.3.1/DCC-Web-0.3.1-source.zip).
