# DCC Web 0.2.4

## English

- Fixes **Profile not found** when installing DCC Remote Access 0.1.0 with a local Docker profile whose ID differs from `local`.
- Restores **DCC Remote Access** in the **DCC** App Store category for eligible local Docker profiles, including installed-state detection.
- Adds grant-scoped AI agent instructions and project ZIPs for all seven MCP clients, including an optional ChatGPT Web variant for Codex.
- Existing profiles, persistent data and local HTTPS are preserved when upgrading through DCC Container Updater. Public access stays disabled until an administrator enables it with MFA and explicit confirmation.
- End-to-end testing with a hosted zrok account remains pending.

[Source ZIP](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.4/DCC-Web-0.2.4-source.zip) · [Remote Access setup](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.4/apps/dcc-remote-access/README.md)

## Polski

- Naprawiono błąd **Profile not found** przy instalacji DCC Remote Access 0.1.0 z lokalnego profilu Dockera, którego ID jest inne niż `local`.
- Przywrócono **DCC Remote Access** w kategorii **DCC** Sklepu aplikacji dla właściwych profili lokalnych wraz z wykrywaniem zainstalowanego modułu.
- Dodano instrukcje agentów zgodne z zakresem grantu i paczki projektu ZIP dla siedmiu klientów MCP, z opcjonalnym wariantem ChatGPT Web dla Codex.
- Aktualizacja przez DCC Container Updater zachowuje profile, trwałe dane i lokalne HTTPS. Dostęp publiczny pozostaje wyłączony do chwili świadomej aktywacji przez administratora z MFA.
- Test end-to-end z kontem hostowanego zrok pozostaje do wykonania.
