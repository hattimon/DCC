# DCC Web 0.2.8

## English

- Allow DCC Container Updater 1.1.4 to pause and resume an active zrok tunnel during compatible updates. Enable this option when activating the tunnel locally with your password and 2FA. Updater waits for the new or restored panel to be healthy before resuming the tunnel.
- The first update from older Web versions still requires the manual stop. DCC Web and Updater show the steps to stop the tunnel, update the panel and enable the tunnel again.

[Source ZIP](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.8/DCC-Web-0.2.8-source.zip) · [Updater 1.1.4](https://github.com/hattimon/DCC/releases/tag/updater-v1.1.4)

## Polski

- DCC Container Updater 1.1.4 może zatrzymać i wznowić aktywny tunel zrok podczas zgodnej aktualizacji. Zaznacz tę opcję przy włączaniu tunelu z lokalnego panelu i potwierdź hasłem oraz kodem 2FA. Updater czeka na gotowość nowego lub przywróconego panelu przed wznowieniem tunelu.
- Pierwsza aktualizacja ze starszej wersji Web wymaga ręcznego zatrzymania tunelu. DCC Web i Updater pokazują kroki wyłączenia tunelu, aktualizacji panelu i ponownego włączenia.
