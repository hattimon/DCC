# DCC Web 0.2.3

## English

- Adds optional DCC Remote Access 0.1.0. After upgrading the existing Web container through DCC Container Updater, open **Settings → Administration and security → Panel access and HTTPS (TLS) → Remote Internet Access**.
- Public access starts disabled. Enabling requires a hosted zrok account, administrator MFA and explicit confirmation. Hosted end-to-end validation with a zrok account remains pending.

[Source ZIP](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.3/DCC-Web-0.2.3-source.zip) · [Remote Access setup](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.3/apps/dcc-remote-access/README.md)

## Polski

- Dodano opcjonalny DCC Remote Access 0.1.0. Po aktualizacji istniejącego kontenera Web przez DCC Container Updater otwórz **Ustawienia → Administracja i bezpieczeństwo → Dostęp do panelu i HTTPS (TLS) → Zdalny dostęp przez Internet**.
- Dostęp publiczny jest domyślnie wyłączony. Aktywacja wymaga konta zrok, MFA administratora i jawnego potwierdzenia. Test end-to-end z kontem hostowanej usługi zrok pozostaje do wykonania.
