# DCC Web 0.2.1

## English

- Show each profile ID below its name in Profiles and show the active profile ID in Overview → Host details.
- Show the selected profile ID beside the host address on the Containers page; it updates when switching profiles.

[Download DCC Web 0.2.1](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.1/DCC-Web-0.2.1-source.zip)

## Polski

- Pokazuj ID pod nazwą każdego profilu oraz ID aktywnego profilu w sekcji „Szczegóły hosta” na ekranie „Przegląd”.
- Pokazuj ID wybranego profilu obok adresu hosta na stronie „Kontenery”; wartość zmienia się po przełączeniu profilu.

[Pobierz DCC Web 0.2.1](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.1/DCC-Web-0.2.1-source.zip)
