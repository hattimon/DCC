# DCC Web 0.2.6

## English

- Accepts hosted Remote Access reservations on `shares.zrok.io` alongside existing `share.zrok.io` addresses.
- Pre-fills a pending reservation and reuses the enrolled zrok environment when setup is resumed.

[Source ZIP](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.6/DCC-Web-0.2.6-source.zip) · [Remote Access setup](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.6/apps/dcc-remote-access/README.md)

## Polski

- Obsługuje rezerwacje Remote Access w domenie `shares.zrok.io` oraz dotychczasowe adresy `share.zrok.io`.
- Podpowiada oczekującą nazwę i wykorzystuje zapisane środowisko zrok przy wznawianiu konfiguracji.

[Paczka źródłowa](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.6/DCC-Web-0.2.6-source.zip) · [Konfiguracja Remote Access](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.6/apps/dcc-remote-access/README.pl.md)
