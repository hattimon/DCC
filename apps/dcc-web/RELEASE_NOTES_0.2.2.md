# DCC Web 0.2.2

## English

- Pause and resume MCP grants. Revoke grants and remove revoked entries from the visible list with explicit checkbox confirmation; the audit record is retained.
- Let Codex select an authorized connection profile by its exact name or host/IP address. Profile IDs remain supported for ambiguous names or addresses.
- Add a manual refresh button beside container search and make the top-right refresh update the full container list.
- Add a 15–900 second refresh interval (default 15 seconds) and an optional change-aware mode. This mode checks a compact Docker container-list revision at the selected interval and fetches details and metrics only after a detected change. Default periodic refresh and pause-on-input behavior remain unchanged.

[Download DCC Web 0.2.2](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.2/DCC-Web-0.2.2-source.zip)

## Polski

- Dodano wstrzymywanie i wznawianie grantów MCP. Odebranie dostępu oraz usunięcie odebranego grantu z listy wymaga jawnego zaznaczenia potwierdzenia; zapis w dzienniku operacji pozostaje zachowany.
- Codex może wybierać dozwolony profil po dokładnej nazwie lub adresie hosta/IP. ID nadal działa, gdy nazwa lub adres są niejednoznaczne.
- Dodano ręczne odświeżanie obok wyszukiwarki kontenerów i odświeżanie całej listy przyciskiem w prawym górnym rogu.
- Dodano interwał 15–900 sekund (domyślnie 15 sekund) i opcjonalny tryb sprawdzania zmian. Tryb okresowo sprawdza skrót listy kontenerów Dockera i pobiera szczegóły oraz metryki dopiero po wykryciu zmiany. Domyślne odświeżanie cykliczne i pauzowanie podczas pisania pozostają bez zmian.
