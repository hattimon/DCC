# DCC Web 0.2.5

## English

- Fixes **Profile not found** when DCC Web checks the result of configuring, enabling or restarting DCC Remote Access in a workspace with a custom Docker profile ID.
- The DCC Web card in the shared catalog points Desktop users to the managed Remote Access entry in the browser panel.

[Source ZIP](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.5/DCC-Web-0.2.5-source.zip) · [Remote Access setup](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.5/apps/dcc-remote-access/README.md)

## Polski

- Naprawiono błąd **Profile not found** podczas sprawdzania wyniku konfiguracji, włączania lub restartu DCC Remote Access, gdy lokalny profil Dockera ma niestandardowy identyfikator.
- Karta DCC Web we wspólnym katalogu wskazuje użytkownikom Desktop, gdzie znaleźć zarządzany moduł Remote Access w przeglądarce.

[Paczka źródłowa](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.5/DCC-Web-0.2.5-source.zip) · [Konfiguracja Remote Access](https://github.com/hattimon/DCC/blob/dcc-web-v0.2.5/apps/dcc-remote-access/README.pl.md)
