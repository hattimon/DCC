# DCC Web 0.3.4

## Polski

- Naprawiono odzyskiwanie dostępu zrok po aktualizacji: DCC Web wysyła teraz wymagany przez API zrok typ danych przy usuwaniu zweryfikowanego, osieroconego udziału. Zachowana rezerwacja i domena pozostają bez zmian.

## English

- Fixed zrok access recovery after updates: DCC Web now sends the media type required by the zrok API when removing a verified stale share. The saved reservation and domain remain unchanged.
