# DCC Web 0.2.0

## English

- Download MCP configuration files, a project ZIP, or a local Codex plugin ZIP. Token values are excluded from the downloads.
- Follow step-by-step token setup for Windows, macOS and Linux from the MCP export dialog.
- See the active SSH host address in the terminal header, including custom ports.

[Download DCC Web 0.2.0](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.0/DCC-Web-0.2.0-source.zip)

## Polski

- Pobieraj konfigurację MCP, paczkę projektu lub ZIP z lokalną wtyczką Codex. Pliki eksportu pomijają wartość tokenu.
- Ustaw token krok po kroku na Windows, macOS i Linuksie według instrukcji w oknie eksportu.
- Sprawdzaj adres SSH aktywnego połączenia i niestandardowy port w nagłówku terminala.

[Pobierz DCC Web 0.2.0](https://github.com/hattimon/DCC/releases/download/dcc-web-v0.2.0/DCC-Web-0.2.0-source.zip)
