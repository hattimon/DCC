# DCC Kiri Manager 0.1.0

**English.** Independent, experimental read-only workspace for Kiri. Inspect containers, images, volumes, networks, Compose services and selected-container metrics. Includes the local connection wizard, PL/EN and light/dark themes.

**Polski.** Samodzielny, eksperymentalny panel Kiri do odczytu metadanych kontenerów, obrazów, wolumenów, sieci i usług Compose. Zawiera monitoring wybranego kontenera, kreator połączenia, język PL/EN i dwa motywy.
