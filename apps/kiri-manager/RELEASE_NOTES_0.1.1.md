# DCC Kiri Manager 0.1.1

**English.** First sign-in on an unconfigured local panel uses `admin / admin`, also shown in the startup log. The browser requires a new password before opening the panel and lets you choose a username. Expand the sign-in help for terminal setup and password reset. Upgrades preserve existing credentials, connection profiles and preferences. Werkzeug 3.1.9 addresses the Windows file path advisory.

**Polski.** Pierwsze logowanie w lokalnym panelu bez konta używa danych `admin / admin`, podanych też w logu startowym. Przed wejściem do panelu ustaw własne hasło i w razie potrzeby zmień nazwę użytkownika. Rozwiń pomoc na ekranie logowania, aby zobaczyć konfigurację i reset z terminala. Aktualizacja zachowuje istniejące dane logowania, profile i ustawienia. Werkzeug 3.1.9 zawiera poprawkę obsługi ścieżek w Windows.
