# DCC Kiri Manager 0.1.2

**English.** DCC detects and verifies a local Windows Kiri engine before offering Connect. Panel installation requires explicit consent and runs a disposable socket preflight as the panel user before creating a container. Existing panels and the dedicated data volume are preserved. Windows and WSL end-to-end support remains NOT VERIFIED until validated on an isolated live Kiri engine.

**Polski.** DCC wykrywa i weryfikuje lokalny silnik Kiri na Windows przed pokazaniem przycisku Połącz. Instalacja panelu wymaga jawnej zgody i tymczasowego testu socketu jako użytkownik panelu przed utworzeniem kontenera. Istniejące panele i dedykowany wolumen danych pozostają bez zmian. Obsługa Windows i WSL pozostaje NOT VERIFIED do czasu testu na odizolowanym, działającym silniku Kiri.
