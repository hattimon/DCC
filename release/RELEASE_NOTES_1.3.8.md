# Docker Control Center v1.3.8

Docker Control Center 1.3.8 introduces broad GUI improvements, the Day and Night themes, an expanded application store and Repo Builder improvements on Windows and Linux.

## English

- Added the `Day` theme above `Light`, using `day.png`, dark text and translucent controls, panels and tables.
- Added the `Night` theme with dedicated dark artwork and a red accent.
- Made menu and drop-down backgrounds opaque so their labels remain readable over artwork.
- Added extra space below the final category row so buttons do not touch the lower frame.
- SmartWAN hero artwork scales to the real frame size and stays separate from the description.
- Search, the application count, manual configuration and online refresh remain in one compact row.
- Every category button is visible at once, with full labels and no scroll range.
- Application rows are about 10% taller, keeping two-line descriptions and descenders visible.
- Container-configuration fields are taller so parameter text is no longer clipped.
- Expanded the application store and Repo Builder workflow for managing catalog entries and repositories.
- Linux DEB now installs the DCC application icon for the desktop launcher/window and adds a dedicated Repo Builder launcher using the same icon.

## Polski

- Dodano motyw `Day` nad `Jasny`, wykorzystujący `day.png`, czarny tekst oraz półprzezroczyste kontrolki, panele i tabele.
- Dodano motyw `Noc` z dedykowaną ciemną grafiką i czerwonym akcentem.
- Ustawiono nieprzezroczyste tło menu i list rozwijanych, aby etykiety były czytelne na tle grafiki.
- Dodano większy odstęp pod ostatnim rzędem kategorii, aby przyciski nie stykały się z dolną ramką.
- Grafika główna SmartWAN skaluje się do rzeczywistego rozmiaru ramki i nie nachodzi na opis.
- Pole wyszukiwania, licznik aplikacji, konfiguracja ręczna i odświeżanie online pozostają w jednym wierszu.
- Wszystkie przyciski kategorii są widoczne jednocześnie, z pełnymi nazwami i bez przewijania.
- Wiersze aplikacji są około 10% wyższe, dzięki czemu dwuwierszowe opisy nie są ucinane.
- Pola konfiguracji kontenera są wyższe, dzięki czemu tekst parametrów nie jest ucinany.
- Rozbudowano sklep aplikacji i Repo Builder do zarządzania wpisami katalogu oraz repozytoriami.
- Pakiet Linux DEB instaluje ikonę DCC dla launchera/okna aplikacji oraz osobny launcher Repo Buildera z tą samą ikoną.
