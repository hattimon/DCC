# Docker Control Center v1.3.10

Small maintenance update for Windows and Linux.

## English — What's new
- Fixed the Windows Infrastructure terminal opening hidden instead of as a visible console.
- Improved Store heading and catalog-status contrast in Day and Light themes on Windows and Linux.
- Tightened container refresh-thread cleanup and deferred periodic auto-refresh while modal workflows such as the Store are open.
- Preserved the working 1.3.9 updater handoff, independent Windows restart and shortcut icon refresh.

## Polski — Co nowego
- Naprawiono terminal Infrastruktury na Windows — otwiera się teraz jako widoczne okno.
- Poprawiono czytelność nagłówków sklepu i statusu katalogu w motywach Dzień i Jasny na Windows i Linux.
- Poprawiono kończenie wątków odświeżania i wstrzymano okresowe auto-odświeżanie podczas otwartych okien modalnych, w tym Sklepu.
- Zachowano działający handoff updatera z 1.3.9, niezależny restart Windows i odświeżanie ikon skrótów.
